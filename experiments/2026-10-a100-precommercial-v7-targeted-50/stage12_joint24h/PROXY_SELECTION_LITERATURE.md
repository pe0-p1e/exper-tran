# Proxy-selection literature and current method scope

Checked primary sources2026-10-21. Current layer-selection priority is FDA-inspired actual conditional utility; ILA is an optional source proposal, never a mandatory weak seed. Stage1 constructs a method; Stage2 validates frozen settings; Stage3 performs full component ablations.

| Paper | Actual mechanism and usable lesson | Protocol boundary/current status |
|---|---|---|
| FiT,ICCV2023, *How to choose your best allies for a transferable attack?* https://arxiv.org/abs/2304.02312 | Selects source models using a few preliminary target queries; evaluation centers distortion rather than one ASR threshold. Model identity must be evaluated, not assumed interchangeable. | Final-target queries cannot select proxies in our protocol. Any analogous empirical selection uses held-out development validators and is disclosed as development feedback. FiT is not implemented as a faithful baseline. |
| AdaEA,ICCV2023 https://arxiv.org/abs/2308.02897 | Adapts fusion according to discrepancy in each surrogate's contribution, with a disparity-reduced update filter. | Dynamic fusion is different from choosing a fixed subset. Our primary attack retains equal normalized fusion; source effectiveness/conflict diagnostics are adaptations, not AdaEA reproduction. |
| CWA,ICLR2024,*Rethinking Model Ensemble in Transfer-based Adversarial Attacks* https://proceedings.iclr.cc/paper_files/paper/2024/hash/53fe824f289060ce705ed7c01dae59d2-Abstract-Conference.html | Common weakness is characterized via landscape flatness and proximity to individual model optima. The method includes SAM/Cosine Similarity Encourager. | A direct warning against interpreting orthogonality alone as useful complementarity. No CWA optimizer/flatness reproduction is claimed for our prototype loss. |
| Yao et al.,ICML2025 https://proceedings.mlr.press/v267/yao25f.html | Transferability-error framework relates vulnerability, diversity and complexity/generalization. | The theorem is not an optimal CKA or gradient-cosine subset rule for our targeted prototype setting. Use as background; require empirical usefulness and measured cost. |
| SEA,arXiv2505.12644v2 https://arxiv.org/html/2505.12644v2 | Separates within-iteration and cross-iteration diversity; Algorithm1 randomly samples a fixed number of models each iteration and fuses logits. Gradient cosine is also used in diversity analysis. | SEA is not a static lowest-CKA subset selector or our gradient-ranked greedy method. Temporal rotation requires a separately declared prototype-gradient adaptation and compute comparison; not currently executed. |

Provisional integrated strategy: keep the fixed1:1 PP image objective; propose native units from source evidence and already evaluated development controls; evaluate additions conditionally using FDA-inspired joint attacks. Proxy identity and native layer identity are jointly selected. Rank candidate additions by measured source strength, nonredundancy, gradient compatibility and estimated marginal cost, but let actual held-out development attack gains/losses determine beam retention. This is a research heuristic, not a theorem or proof of global optimality.

Revision2 corrects a failed assumption: maximizing source-relative ILA disturbance and minimizing source cost did not identify an effective PP seed (CLIP21:0/10; CLIP11+21:2/10 on Qwen9). Keep those results and the old search trace. Start from existing effective singleton/pair measurements; retain parents so a harmful addition is not compulsory. ILA remains optional. No final target or commercial responses participate in this change.

Novelty limits: gradient cosine, model diversity, adaptive ensemble contributions and feature-space attacks have substantial prior literature. CKA does not by itself provide a new theory. The testable question is whether useful native model–layer complementarity can yield stronger or similarly effective targeted transfer at lower measured cost, with honest held-out validation. Results remain to be established.
