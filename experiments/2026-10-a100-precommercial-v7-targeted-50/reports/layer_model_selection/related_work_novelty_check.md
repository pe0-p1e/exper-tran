# Related-work check: multi-model and multi-layer novelty

2026-10-20. This is a focused search, not an exhaustive priority claim. Implementation of the requested ILA/FDA-inspired experiment is still pending; no new faithful-reproduction results exist.

- FDA(N), NeurIPS2020: multi-intermediate-layer targeted feature-distribution attack, auxiliary class predictors, held-out greedy layer search. Section4.1.2 compares adding layers to adding models in a conventional ensemble; that comparison alone is NOT evidence of a joint multi-model/multi-layer FDA implementation. https://proceedings.neurips.cc/paper/2020/file/eefc7bfe8fd6e2c8c01aa6ca7b1aab1a-Paper.pdf
- MFAA, TIFS2025: *Enhancing the Transferability of Adversarial Attacks via Multi-Feature Attention*, DOI10.1109/TIFS.2025.3526067. Publisher abstract explicitly describes multi-layer aggregation and reports both single-model and ensemble experiments. Closely relevant prior art. The inspected public entry point is single-model; the exact ensemble implementation and whether every component uses the same multi-layer mechanism require full-paper/code verification. The term ensemble attention must not automatically be interpreted as a multi-checkpoint ensemble. https://ieeexplore.ieee.org/document/10833658/ ; official source https://github.com/KWPCCC/MFAA
- FTM, CVPR2025: *Improving Transferable Targeted Attacks with Feature Tuning Mixup*. Main text describes learnable perturbations across multiple layers and an ensemble extension; also has an MLLM evaluation appendix. Its core is feature augmentation plus output-logit objective, rather than directly optimizing source/target prototype distances at selected visual blocks. It is counterevidence to a broad claim that multi-model plus multi-layer targeted transfer has never been explored. https://arxiv.org/html/2411.15553v2
- Yao et al., ICML2025: *Understanding Model Ensemble in Transferable Adversarial Attack*. Defines transferability error, diversity and empirical ensemble Rademacher complexity; derives bounds/decomposition and reports54-model experiments. Directly relevant to the motivation for diversity and generalization, but does not automatically establish our targeted prototype-loss model-layer subset rule. https://proceedings.mlr.press/v267/yao25f.html

Safe positioning: investigate the interaction between heterogeneous visual backbones and model-specific intermediate layer subsets in language-head-free prototype targeted transfer; test useful complementarity, interference, and minimal measured compute. These are candidate research questions, not established first-of-their-kind contributions. Avoid claiming that nobody explains transferability or that simply combining models and layers is novel. Need compare exact objective, representation, selection information, optimization budget and evaluation task for each nearest prior work.

Paper core implementation remains separate work: ILA baseline-direction projection and layer-specific disturbance propagation; FDA auxiliary distribution predictors or a clearly labeled prototype adaptation; conditional subset validation rather than ranking singles. Do not describe existing predeclared quartile/non-quartile pilots as these implementations.

## Narrow visual-only/loss/ensemble claim: additional check

The claim that no similar visual-space objective plus model ensemble exists is not supported. FOA-Attack (NeurIPS2025), already in our baseline preparation, is especially close: image-to-target-image global cosine alignment, local clustered optimal transport, and dynamic multi-surrogate weighting. It establishes overlap in visual feature alignment and multi-model generation; it does not by itself establish the same model-specific intermediate-layer subset selection or class-centroid source-push objective. Primary source: https://papers.neurips.cc/paper_files/paper/2025/hash/540a3bf4863672cdaebfed69fa2ce335-Abstract-Conference.html .

FDA+ms (ICLR2020) explicitly maximizes target class feature-distribution probability while minimizing source probability. Its learned auxiliary probabilities differ from our cosine prototypes, but the source/target pull-push idea already exists. Primary author-hosted paper: https://kevinjliang.github.io/files/Feature_Distribution_Attack.pdf .

Also discovered *Push & Pull: Transferable Adversarial Examples With Attentive Attack*, Gao et al., TMM24:2329–2338,2022 (online2021), DOI10.1109/TMM.2021.3079723. Available abstract records mention source/target cluster centroids and triplet loss. Full primary text/formulas and its exact ensemble configuration remain to be verified; do not claim a confirmed exact match or exact difference from abstract mirrors alone.

Remaining defensible statement: no exact match to the complete current combination has been established by this limited search. This is not proof of absence, and an exact implementation combination alone need not be a substantive scientific contribution. Prioritize causal interaction tests, useful complementarity, native model-specific selection and compute-controlled confirmation.
