# V6 report package

This curated package contains the final report, completion and cell-level summary tables, all report-relevant measurement/validation data, all 120 joint PCA/t-SNE figures, model/performance audits, and four real clean/adversarial example PNGs (two cross-family and two intra-family). Large intermediate work directories, the full attack-image set, reference-image collection, and cached embeddings are intentionally excluded from this GitHub package. They remain in the full local checkpoint archive.

The full 2.3 GB checkpoint is stored at `/home/ubuntu/a100_precommercial_v6_checkpoint_20261009.tar.zst`; its adjacent `.sha256` file verifies the archive. `MANIFEST.sha256` covers every file in this curated package except itself.
